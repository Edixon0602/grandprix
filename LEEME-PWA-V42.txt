INSTALACIÓN
-----------
Extraer en la raíz del dashboard aceptando reemplazar. No abrir ningún instalador.
El sitio debe estar servido por HTTPS para que el navegador permita instalar una PWA.

COMPORTAMIENTO
--------------
- Chrome/Edge/Android: cuando el navegador emite beforeinstallprompt, aparece una tarjeta “Instalar”.
- iPhone/iPad: se muestra la instrucción Compartir → Añadir a pantalla de inicio.
- Si ya está abierta como aplicación instalada, la tarjeta no aparece.
- Los Service Workers Admin y Cliente usan cachés independientes y ya no se borran entre sí.
- No se cachean API, pagos, datos de clientes ni HTML autenticado. Solo recursos estáticos; sin conexión se muestra una pantalla neutra.
